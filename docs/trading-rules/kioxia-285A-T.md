## ステップ2: 期待値最大化トレードルール TOP 10

### Rule 1: 大陽線モメンタム継続ロング ⭐⭐⭐⭐⭐

```
セットアップ : 当日終値が始値から +3% 超の大陽線（前場・後場問わず）
エントリー   : 翌日寄り付き成行買い（9:00〜9:05）
ターゲット   : 始値から +3%
ストップ     : 始値から -2%
保有時間     : 最長当日中（6時間以内）
```

**データ根拠**: 前日+3%超 → 翌日平均騰落+5.55%（n=16）。強モメンタムが最も信頼度高い。  
**発生頻度**: 月2〜3回  
**注意点**: +5%超の場合はターゲットを+5%に拡張可能（翌日avg+7.63%）

---

### Rule 2: ギャップダウン逆張りロング（ギャップ埋め狙い） ⭐⭐⭐⭐

```
セットアップ : 前日比 -0.5% 超のギャップダウン始値
エントリー   : 寄り付き後 15 分（9:00〜9:15）で成行買い
ターゲット   : 前日終値（ギャップ埋め）
ストップ     : 始値からギャップ幅の 1.5 倍下（例: ギャップ-3% なら -4.5% 下）
保有時間     : 最長 3 時間
```

**データ根拠**: ギャップダウンの70%が当日中に前日終値を回復。逆張り優位性あり。  
**発生頻度**: 月1〜2回  
**注意点**: 市場全体が急落している日（指数-2%超）は見送る

---

### Rule 3: 大陰線モメンタム継続空売り ⭐⭐⭐⭐

```
セットアップ : 当日終値が始値から -3% 超の大陰線
エントリー   : 翌日寄り付き成行空売り（9:00〜9:05）
ターゲット   : 始値から -3%
ストップ     : 始値から +2%
保有時間     : 最長当日中（6時間以内）
```

**データ根拠**: 前日-3%超 → 翌日平均騰落-5.83%（n=10）。下落モメンタムも強く持続。  
**発生頻度**: 月1〜2回  
**注意点**: 空売り規制・信用残高に注意。強い上昇トレンド下での逆張りリスクを意識

---

### Rule 4: 前日高値ブレイクアウトロング ⭐⭐⭐⭐

```
セットアップ : 当日始値または前場 30 分以内に前日高値を更新
エントリー   : 前日高値を 0.3% 超えた瞬間の成行買い（確認ありエントリー）
ターゲット   : ブレイク価格から +2%
ストップ     : 前日高値を再び下回ったら（フォルスブレイク判定）
保有時間     : 最長 3 時間
```

**データ根拠**: 67%の日で前日高値ブレイク発生、ブレイク日の平均騰落+1.13%。  
**発生頻度**: 月4〜5回（最頻出）  
**注意点**: ギャップアップで始値が既に前日高値超えの場合は §5 のRule確認後判断

---

### Rule 5: ギャップアップ維持確認後の継続ロング ⭐⭐⭐

```
セットアップ : +1% 超ギャップアップ始値
確認条件     : 前場 30 分（9:30 まで）に始値付近まで下げず、ギャップを埋めない
エントリー   : 9:30 の時点でギャップ非埋め確認 → 成行買い
ターゲット   : 始値から +2%
ストップ     : 始値を 1% 下回ったら
保有時間     : 最長 4 時間（後場 2:00 まで）
```

**データ根拠**: ギャップアップ>1%の63%はギャップを埋めず、維持日の当日騰落平均+2.26%。  
**発生頻度**: 月8〜9回  
**注意点**: 前場30分でギャップを一度でも埋めた日はスキップ（Rule 2 or 非エントリー）

---

### Rule 6: 月曜日初動追いロング ⭐⭐⭐⭐

```
セットアップ : 月曜日の寄り付き（9:00）
確認条件     : 寄り付き後 15 分（9:15 まで）に始値比 +0.5% 以上の陽線確認
エントリー   : 9:15 前後の成行買い
ターゲット   : 始値から +2%
ストップ     : -1%
保有時間     : 当日中（最長 6 時間）
```

**データ根拠**: 月曜の上昇率68%・平均騰落+1.11%は全曜日最強。初動確認で精度向上。  
**発生頻度**: 月2〜3回（月曜のうち初動陽線のもの）  
**注意点**: 前週金曜に大陰線があった翌月曜は Rule 3 と組み合わせ考慮

---

### Rule 7: 水曜日高ボラ方向追随 ⭐⭐⭐⭐

```
セットアップ : 水曜日の寄り付き
確認条件     : 前場 30 分（9:30 まで）の初動方向が始値比 ±0.5% 以上
エントリー   : 初動方向に追随（上 → ロング / 下 → ショート）
ターゲット   : ±3%
ストップ     : ∓1.5%（逆方向リターン）
保有時間     : 最長 4 時間
```

**データ根拠**: 水曜日は全曜日最大レンジ（平均7.17%）。3%目標に十分な値幅。  
**発生頻度**: 月3〜4回  
**注意点**: 水曜日特有の季節性は限定的サンプル（n=17）。継続モニタリング要

---

### Rule 8: 前日安値フォルスブレイク逆張り ⭐⭐⭐

```
セットアップ : 前日安値を一時的に下回る動き（当日始値または前場中）
確認条件     : 安値ブレイク後 30 分以内に前日安値まで回復
エントリー   : 前日安値を回復した直後の成行買い
ターゲット   : 前日安値から +2%（= 前日安値 × 1.02）
ストップ     : フォルスブレイク時安値をさらに 0.5% 下回ったら
保有時間     : 最長 2 時間
```

**データ根拠**: 前日安値ブレイクの45%は当日中に回復（フォルスブレイク）。回復日の終値平均+1.12%。  
**発生頻度**: 月2〜3回  
**注意点**: 強い下落トレンド日（Rule 3 のセットアップ日）は適用しない

---

### Rule 9: 高出来高ブレイクアウト（レアイベント大値幅狙い） ⭐⭐⭐⭐⭐

```
セットアップ : 出来高が 20 日平均の 1.5 倍超（前場 1 時間で判断）
確認条件     : 前場 30 分で初動方向 ±1% 以上確認
エントリー   : 初動方向に成行エントリー
ターゲット   : ±5%（通常の 1.5〜2 倍）
ストップ     : ∓2%
保有時間     : 当日中（最長 6 時間）
```

**データ根拠**: 高出来高日の平均レンジ11.11%（通常比約+54%）。5%目標も十分射程内。  
**発生頻度**: 月1回以下（レア）  
**注意点**: 出来高急増の「理由」確認推奨（決算・ニュース・株主還元発表等）

---

### Rule 10: 3日連続陽線後の押し目買い ⭐⭐⭐

```
セットアップ : 直近 3 営業日が連続陽線（終値 > 始値 × 3 日間）
確認条件     : 翌日（4 日目）に -1% 以上の押し（前日終値比）
エントリー   : 押し確認後 15 分以内（リバウンド初動）の成行買い
ターゲット   : 押し入り価格から +2%
ストップ     : 押し安値からさらに -2%
保有時間     : 最長 4 時間
```

**データ根拠**: 3連続陽線後の翌日上昇率100%・平均騰落+3.71%（n=11）。押しは買いチャンス。  
**発生頻度**: 月1〜2回  
**注意点**: 連続陽線後に+10%超の過熱感があれば少し待ってから入ること

## 共通リスク管理ルール

1. **1トレード最大リスク**: 資金の 2% 以内
2. **1日の損失上限**: 資金の 4%（2連敗でその日は終了）
3. **利益確定**: ターゲット達成前でも後場 2:55（大引け 5 分前）には全決済
4. **強制撤退**: 指数（TOPIX）が -2% 超の日は Rule 2/8/10 のみ（逆張り系は除外）
5. **バックテスト注意**: n=6〜32の小サンプル。全ルールをリアルタイムで検証継続すること

## 特性サマリー：なぜこの銘柄は短期トレードに向くか

- **平均日中レンジ 7.23%**: 東証プライム平均（1〜2%）の約4倍
- **ATR 7.58%**: ストップ設定とターゲット設定に十分な空間
- **モメンタム継続性が高い**: 前日大陽線後の翌日avg+5.55%は逆張りを圧倒
- **上昇トレンド継続中**: 6ヶ月+250.7%、直近1ヶ月もレンジ拡大
- **ギャップ構造**: 平均+2.63%ギャップアップ → ギャップ戦略が有効
